# 📤 NAT Gateway

**An AWS NAT Gateway enables instances in a private subnet to access the internet or other AWS services, without allowing inbound traffic from the internet. It _must_ use a static Elastic IP to ensure session stability and allow IP-based whitelisting.**

---

## 📖 What Is a NAT Gateway?

A **NAT (Network Address Translation) Gateway** is a managed AWS service that:

- Allows **outbound internet access** from **private subnets**
- Blocks **inbound traffic** from the internet
- Automatically scales and is highly available within an Availability Zone

---

## 🧰 Key Use Cases

- **Private EC2 instances accessing the internet**  
  For downloading updates, accessing APIs, or sending telemetry without exposing them publicly.

- **Whitelisting IPs for external services**  
  External APIs or SaaS platforms often require a known public IP. NAT Gateway provides a _fixed Elastic IP_ for this.

- **Secure architecture**  
  Keeps sensitive workloads in private subnets while still enabling outbound connectivity.

- **Overlapping VPC communication**  
  NAT Gateway can help route traffic between VPCs with overlapping CIDRs using translation.

Sources: [AWS NAT Gateway use cases](https://docs.aws.amazon.com/vpc/latest/userguide/nat-gateway-scenarios.html), [CloudOptimo guide](https://www.cloudoptimo.com/blog/comprehensive-guide-to-nat-gateway-configuration-use-cases-and-best-practices/)

---

## 📌 Why Use a Static IP (Elastic IP)?

- **Session stability:** Dynamic IPs would break long-lived connections.
- **IP allowlisting:** External services often require a known IP.
- **Audit and traceability:** Easier to monitor and log traffic from a consistent source.

As per AWS design, **Elastic IP is mandatory** for NAT Gateway.

---

## ⚠️ Considerations

| Feature                | NAT Gateway | NAT Instance (EC2)            |
| ---------------------- | ----------- | ----------------------------- |
| Managed by AWS         | ✅ Yes      | ❌ No                         |
| Scales automatically   | ✅ Yes      | ❌ Manual                     |
| Requires Elastic IP    | ✅ Yes      | ⚠️ Optional but recommended   |
| Cost                   | 💰 Higher   | 💸 Lower but more maintenance |
| Security & reliability | ✅ High     | ⚠️ Depends on setup           |
