# 💂🏻 [What is AWS CloudFormation Guard?](https://docs.aws.amazon.com/cfn-guard/latest/ug/what-is-guard.html)

## 📌 What Is cfn-guard?

**AWS CloudFormation Guard** (aka `cfn-guard`) is an **open-source policy-as-code tool** that allows you to **validate CloudFormation templates** against **custom rules** — ensuring your infrastructure is **secure, compliant, and consistent** before deployment.

It prevents “bad templates” from being deployed by checking for things like:

✅ Encrypted S3 buckets  
✅ Limited IAM permissions  
✅ Allowed instance types  
✅ Mandatory tags  
✅ Blocked CIDR ranges

## 🧰 Components of cfn-guard

### 🟦 1. **Rules File (`.guard`)**

You define your policies in `.guard` syntax:

```hcl
# S3 buckets must be encrypted
Resources.*[ Type == "AWS::S3::Bucket" ].Properties.BucketEncryption != null

# EC2 instances must use approved types
Resources.*[ Type == "AWS::EC2::Instance" ].Properties.InstanceType IN ["t3.micro", "t3.small"]
```

### 🟨 2. **CloudFormation Template (YAML/JSON)**

Your stack template that needs to be validated.

### 🟩 3. **Guard CLI**

You run the `cfn-guard` CLI to validate the template against the rules.

```bash
cfn-guard validate \
  --data template.yaml \
  --rules rules.guard
```

## 💡 Basic Rule Syntax

| Expression     | Meaning                                |
| -------------- | -------------------------------------- |
| `!= null`      | Field must be present                  |
| `==` / `!=`    | Equality check                         |
| `IN [...]`     | Must match one of the values           |
| `NOT IN [...]` | Must _not_ match any value             |
| `Resources.*`  | Wildcard to iterate over all resources |

---

## ✅ Example Rules

### 🔐 Require encryption for all S3 buckets

```hcl
Resources.*[ Type == "AWS::S3::Bucket" ].Properties.BucketEncryption != null
```

### 🏷 Enforce mandatory tags on all resources

```hcl
Resources.*.Properties.Tags[? Key == "Environment" ] != null
Resources.*.Properties.Tags[? Key == "Owner" ] != null
```

### 🧱 Only allow certain EC2 instance types

```hcl
Resources.*[ Type == "AWS::EC2::Instance" ].Properties.InstanceType IN ["t3.micro", "t3.small"]
```

## 🧪 Sample Validation Run

```bash
cfn-guard validate \
  --data mytemplate.yaml \
  --rules secure.guard
```

📤 **Output:**

```bash
X Resources.MyS3Bucket.Properties.BucketEncryption != null: [null] was null
X Resources.MyEC2.Properties.InstanceType IN ["t3.micro", "t3.small"]: [t2.micro] not in allowed list
```

🚫 Deployment blocked until fixes are made.

## 🛠 Use in CI/CD

Add to your CI pipeline (e.g., GitHub Actions, CodePipeline):

```yaml
- name: Validate CloudFormation using cfn-guard
  run: |
    cfn-guard validate \
      --data mytemplate.yaml \
      --rules compliance.guard
```

✅ Prevents non-compliant templates from reaching production.

## 🔐 Governance Use Cases

| Use Case                                  | Sample Rule                                                                   |
| ----------------------------------------- | ----------------------------------------------------------------------------- |
| Ensure all IAM roles have least privilege | `"Action" NOT IN ["*"]`                                                       |
| Disallow public IPs on EC2                | `.AssociatePublicIpAddress == false`                                          |
| Require log retention                     | `Resources.*[Type == "AWS::Logs::LogGroup"].Properties.RetentionInDays >= 14` |
