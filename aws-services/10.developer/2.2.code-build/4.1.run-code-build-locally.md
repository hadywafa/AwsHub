# Run Code Deploy Locally

- In case of need of deep troubleshooting beyond logs…
- You can run CodeBuild locally on your desktop (after installing Docker)
- For this, leverage the CodeBuild Agent
- [https://docs.aws.amazon.com/codebuild/latest/userguide/use-codebuildagent.html](https://docs.aws.amazon.com/codebuild/latest/userguide/use-codebuildagent.html)
