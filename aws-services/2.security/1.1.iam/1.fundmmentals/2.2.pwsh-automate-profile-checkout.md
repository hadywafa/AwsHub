# 🎨 Smart AWS Profile Switching in PowerShell with Oh My Posh + FZF

This guide documents how to create a **stylish, interactive AWS profile switcher** in PowerShell using:

- 🟧 **Oh My Posh** for prompt styling
- 🟦 **FZF** for fuzzy profile selection
- 🟨 **PowerShell** for scripting
- 🟩 **AWS CLI** for verification

---

## 📦 Prerequisites

Ensure the following tools are installed:

| Tool         | Purpose                            | Install Command (Scoop)    |
| ------------ | ---------------------------------- | -------------------------- |
| `aws-cli`    | AWS command-line interface         | `scoop install aws`        |
| `fzf`        | Fuzzy finder for profile selection | `scoop install fzf`        |
| `oh-my-posh` | Prompt styling engine              | `scoop install oh-my-posh` |

---

## 🧠 Concept

We use `AWS_PROFILE` to control which profile is active. Oh My Posh reads this environment variable and displays it in the prompt. FZF lets us interactively choose a profile from `~/.aws/config`.

---

## 🎯 Goal

- Switch AWS profiles interactively
- Reflect the active profile in the prompt
- Verify credentials with `aws sts get-caller-identity`

---

## 🛠️ PowerShell Function: `awsuse`

Add this to your PowerShell profile (`$PROFILE`):

```powershell
function Set-AWSProfile {
    # Extract profile names from ~/.aws/config
    $profiles = Get-Content "$HOME\.aws\config" |
        Where-Object { $_ -match '^\[profile (.+)\]' } |
        ForEach-Object {
            if ($_ -match '^\[profile (.+)\]') { $matches[1] }
        }

    # Use fzf to select a profile
    $profile = $profiles | Sort-Object -Unique | fzf

    if ($profile) {
        $env:AWS_PROFILE = $profile
        Write-Host "Switched to AWS profile: $env:AWS_PROFILE" -ForegroundColor Cyan
        aws sts get-caller-identity --output json
    }
}
```

---

## 🎨 Oh My Posh Segment: AWS

Add this to your Oh My Posh theme JSON:

```json
{
  "type": "aws",
  "style": "diamond",
  "leading_diamond": "\ue0b6",
  "trailing_diamond": "\ue0b4 ",
  "template": "\ue7ad {{.Profile}}{{if .Region}}@{{.Region}}{{end}}",
  "foreground": "#faa029",
  "background": "#565656",
  "properties": {
    "cache_duration": "none"
  }
}
```

This renders something like:

```ini
 orchida@me-central-1
```

---

## 🧪 Usage

```powershell
awsuse
```

- FZF opens with a list of profiles
- You select one (e.g., `orchida`)
- `AWS_PROFILE` is set
- Oh My Posh updates instantly
- AWS CLI confirms identity

---

## 🧩 Real-World Analogy

Think of this setup like a **smart badge system**:

- You wear a badge (`AWS_PROFILE`)
- Your terminal shows your badge (`Oh My Posh`)
- You scan it to verify access (`aws sts get-caller-identity`)
- You can swap badges instantly (`awsuse` + `fzf`)

---

## 🧠 Best Practices

- Keep profile names consistent across `config` and `credentials`
- Use descriptive names like `dev`, `prod`, `orchida`, `issi`
- Add region/output to each `[profile xyz]` block
- Use `aws sts get-caller-identity` to verify credentials
